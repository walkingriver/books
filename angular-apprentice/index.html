Here's the gap: Most beginner Angular content teaches pieces. This book builds one complete app — and deploys it.

One App. Every Step. A Live URL at the End.

Michael D. Callaghan has taught Angular since 2016 on Pluralsight, Udemy, and in workshops. Angular Apprentice is the guided path he wished existed: build Ends Well, a TV series discovery app, step by step with Angular 22 and Angular Material.

Browse series, search and filter lists, open detail pages, and record ratings as you learn standalone components, signals, routing, services, dependency injection, and template-driven forms. Connect optional live TMDb data when you're ready. Then deploy to Cloudflare Pages and finish with a public HTTPS URL you can share.

Not a reference encyclopedia. Not a pile of snippets. One real app — from shell to production.

What You'll Build

Ends Well — a complete TV series discovery app with Angular Material. Not a toy. A portfolio piece you can open in a browser.

Modern Angular 22

Standalone components, signals, computed values, and flow control — patterns you'll use on real projects.

Angular Material

Layout, cards, forms, navigation, and a responsive app shell that looks professional from day one.

Routing & Services

Route params, dependency injection, RatingsService, and SeriesService for real data flow.

Search, Filter & Sort

Interactive lists with pagination, ratings, and optional live TMDb data via HttpClient.

Form Validation

Template-driven forms with validators — the patterns behind every data-entry screen you'll build.

Deploy to Cloudflare Pages

Walk through deployment and finish with a public HTTPS URL on *.pages.dev you can share.

Perfect For

  • HTML-literate beginners — your first Angular book
  • Developers switching from React, Vue, or other frameworks
  • Anyone who learns best by building one real project start to finish
  • Developers ready to continue with the PWA sequel when the app is live

Mock data works offline through most of the book. Live TV data is optional in later chapters. Sample code is available on GitHub.

About the Author

Michael D. Callaghan has shipped software since 1995 for HP, Compaq, Dell, Disney, startups, and enterprises. He has taught Angular since 2016 and trains on Pluralsight and Udemy.

Other technical books include Build Mobile Apps with Ionic and Developing Progressive Web Applications with Angular (2nd ed.) — the natural sequel when your Ends Well app is live.
